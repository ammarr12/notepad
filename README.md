## 🚀 Getting Started

### 🧰 Prerequisites

Make sure you have:

🐍 Python 3.x installed

📦 Standard libraries (no extra installs if you’re using tkinter) — it comes with Python!

📦 Installation & Usage

Clone this repo:

`git clone https://github.com/ammarr12/notepad.git`


Navigate into directory:

`cd notepad`


Run the app:

`python notepad.py`


🎉 That’s it — your notepad should open up as a window you can type in! 
GitHub

## 🧠 How It Works

This app is using Python’s GUI toolkit (e.g., tkinter) to build a window and text box.
It includes:

A menu bar with File → Open / Save

Editing and formating options e.g font color

Simple file handling functions to load and save .txt files

Note: Let me know if you want a code walkthrough or improvements like font size selectors, undo/redo, or dark mode!
